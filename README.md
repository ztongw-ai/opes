# OPES · AI 生成 PPT 评估标准

**Open Presentation-generation Evaluation Standard**（中文工作名：明鉴）

一把公开的尺子，用来评估"AI 生成的 PPT 好不好"，以及"这个 AI PPT 工具好不好用"。适合个人选工具、自媒体做横评、开发者做技术评测、企业做采购选型。

它只规定怎么量，不替任何人打分。

## 怎么用

**直接打开评分卡**：https://ztongw-ai.github.io/opes/

逐项点分，实时出总分、九维雷达图、S/A/B/C 评级和最差项，可以切换权重档、导出结果。页面完全离线运行，数据不离开你的浏览器。

**想装在自己电脑上**：把下面这句话发给你的 Agent（Claude Code、Codex、Cursor 等能操作电脑的都可以），它会帮你下载、打开，并带你走一遍评测流程：

```
帮我装上这个 PPT 评分工具并打开：https://github.com/ztongw-ai/opes
```

也可以自己动手：下载本仓库，双击 [index.html](index.html)。

分数由你自己打。Agent 只负责安装和陪跑，具体约定见 [AGENT.md](AGENT.md)。

## 这把尺子的四个设计

1. **三层九维**：不只看成品。成品力（内容、视觉、表达）、生成力（交互、效率、交付）、可信力（稳定、数据安全、成本）。
2. **每一分都有依据**：40 个子指标，每项的 1 / 3 / 5 分都有文字锚点；能测量的一律测量。
3. **一票否决**：编造数据、配图张冠李戴、文件打不开、声称私有却数据出域——触发任意一条，评级封顶 C。
4. **权重可调**：同一份打分，套通用、自媒体、企业采购、技术四档权重，得到不同视角的结论。权重全部公开，可以自己改。
