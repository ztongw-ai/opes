# 明鉴 · 公开题集与施测手册

**OPES Public Prompt Set & Runbook｜配套《AI 演示生成评估框架 v0.1》**

> 版本 v0.1 ｜ 日期 2026-07-01
> 用途：横评各家 AI 生成 PPT 工具（豆包 / Kimi / Codex / Genspark / Manus / 天工 Skywork / Gamma / AiPPT …）时，向**所有工具投喂完全相同的提示词**，保证结论可比、中立、可复现。
> 原则：题集**公开、固定、分层**；提示词逐字复用；产物盲评。任何人可用同一题集复评他人结论。

---

## 一、分层设计

结论要中立，覆盖面就必须撑得起。本题集沿三条轴分层，规模化时按格加密：

- **体裁**（6）：商业路演 / 工作汇报 / 教学课件 / 产品发布 / 数据报告 / 个人分享
- **输入形态**（5）：一句话命题 / 详细 brief / 长文档转 PPT / 数据表转 PPT / 输入即大纲
- **难度专项**（4）：常规 / 强时效（需联网检索） / 强源材料忠实（给定资料不得跑偏） / 复杂数据可视化

|---|---|---|---|---|
| Q01 | 商业路演 | 一句话命题 | 常规 | 无信息时的选题/结构/惊艳度 |
| Q02 | 工作汇报 | 详细 brief | 常规 | 忠实需求、要点覆盖、正式度 |
| Q03 | 教学课件 | 一句话命题 | 常规 | 讲授逻辑、单页负载、可读性 |

## 二、题目正文（逐字投喂）

> 使用规则：把「提示词」整段**原样复制**到每个工具，不得为某工具改写、补充或提示。需要附件的题，统一上传同一份附件。

### Q01 · 商业路演 · 一句话命题
```
帮我做一份面向投资人的融资路演 PPT，主题是"面向中小餐饮的 AI 智能排班 SaaS"，
A 轮，约 12 页。要有问题、方案、市场、商业模式、竞争、团队、财务预测、融资用途。
```
考察：无补充信息时的行业理解、路演标准结构、说服力与惊艳度。

### Q02 · 工作汇报 · 详细 brief
```
帮我做一份 2026 上半年市场部工作总结汇报，向公司管理层汇报，约 10 页。
需要包含：上半年 3 个核心目标的完成情况（获客成本下降 18%、私域用户增长 40 万、
品牌搜索指数 +25%）、3 个典型项目复盘、遇到的 2 个主要问题及对策、下半年规划与资源需求。
风格正式、克制、数据说话，适合投屏汇报。
```
考察：忠实需求、要点全覆盖、汇报体裁的正式度与克制。

### Q03 · 教学课件 · 一句话命题
```
帮我做一节面向高中生的物理课件 PPT，讲"牛顿第二定律"，约 15 页，
要有概念引入、公式推导、生活实例、典型例题、课堂小结。语言通俗，一页讲一个点。
```
考察：讲授逻辑、单页信息负载、通俗性、可读性。

### Q04 · 产品发布 · 详细 brief
```
帮我做一份新品发布会主题 PPT，产品是一款主打"超长续航 + 隐私安全"的国产旗舰手机，
面向发布会大屏演讲，约 14 页。要有悬念开场、痛点、核心卖点（续航 3 天 / 端侧隐私芯片 /
影像升级）、参数、价格、上市信息、金句收尾。视觉要有冲击力、大字少字、发布会气质。
```
考察：叙事节奏、视觉惊艳、发布会场景适配、"能上台讲"。

### Q05 · 数据报告 · 数据表转 PPT · 复杂数据可视化
```
根据我上传的销售数据表，做一份季度经营分析 PPT，约 8 页。
要有整体概览、分区域对比、分品类趋势、同比环比、异常洞察与建议。
图表要选对类型、标注清晰、不误导。
【附上传：附件A-季度销售数据.csv】
```
考察：图表选型正确性、数据可视化准确性、从数据里读出洞察。

### Q06 · 个人分享 · 一句话命题
```
帮我做一份朋友聚会上分享的旅行 PPT，主题"一个人的冰岛环岛 10 天"，约 12 页，
轻松、有故事感、图文并茂，像在讲故事而不是做报告。
```
考察：语气适配、轻松感、审美、叙事感。

### Q07 · 商业路演 · 长文档转 PPT · 强源材料忠实
```
把我上传的商业计划书（约 6000 字）浓缩成一份 12 页的路演 PPT。
只能用文档里的事实与数据，不许编造或夸大；文档没有的内容不要自己补。
【附上传：附件B-商业计划书.md】
```
考察：长文提炼、结构重组、**不失真不编造**（核对 1.1 事实准确性硬否决）。

### Q08 · 工作汇报 · 输入即大纲
```
按我给的大纲原样做成 PPT，不要增删章节、不要改变顺序，每个二级标题一页：
一、项目背景  二、目标与范围  三、里程碑进度（M1已完成/M2进行中/M3未启动）
四、风险与应对  五、资源需求  六、下一步计划
```
考察：是否**忠实执行给定大纲**、不擅自增删改序。

### Q09 · 教学课件 · 长文档转 PPT · 强源材料忠实
```
把我上传的科普长文改写成一份面向初中生的课件 PPT，约 12 页，
保持文中事实准确，用词更通俗，配合适的示意，一页一个知识点。
【附上传：附件C-科普长文.md】
```
考察：长文压缩 + 受众改写 + 事实忠实的平衡。

### Q10 · 数据报告 · 详细 brief · 强时效
```
做一份"截至评测当日、最近一个季度中国新能源汽车市场"的数据简报 PPT，约 8 页，
包含最新销量、品牌份额、增速、出口、趋势判断。数据要联网查最新的，标注来源与时间。
```
考察：**联网检索最新数据的能力与时效准确性**、来源标注。

### Q11 · 产品发布 · 一句话命题 · 强时效
```
做一份"当前 AI 编程助手赛道最新格局"的分享 PPT，约 10 页，
涵盖截至评测当日的主流产品、最新能力进展、价格与差异。信息要新、要有出处。
```
考察：检索行业最新动态并成稿、信息新鲜度与出处。

### Q12 · 数据报告 · 数据表转 PPT · 复杂数据可视化
```
根据上传的多维数据表，做一份 8 页数据洞察 PPT：
要体现"构成（占比）、趋势（时间序列）、对比（分组）、相关（两变量关系）"四类分析，
每类选用恰当图表，避免 3D 饼图等误导性图形，标题写结论而非描述。
【附上传：附件D-多维数据.csv】
```
考察：多种图表选型、结论式标题、避免误导性可视化。

## 三、施测手册（Runbook）

### 快速人工版（模式 A）
1. 选题：从题集抽 3–6 题，覆盖至少 3 种体裁。
2. 同题同词投喂每个工具，**同一时间窗内**跑完；记录工具版本、时间戳。
3. 现场记客观项：生成时延、返工次数、过程稳定性、导出/演讲/编辑能力、单份成本。
4. 用《交互式评分卡》逐维打分 → 出总分 + 雷达 + 最差项。
5. 报告须注明：单人、非盲、主观——如实标注局限。

### 严谨复现版（模式 B）
1. **全量同题同词**投喂所有工具；附件对所有工具一致提供。
2. **产物标准化**：每页渲染截图 + 提取文字；隐去工具名（盲评）。
3. **多人独立评分**：每样本 ≥2 名评分者独立打分；用逐项锚点。
4. **仲裁**：分歧样本（分差 >20% 或评级不一致）交第三人定稿。
5. **一致性校验**：报告评分者一致性 ρ；ρ<0.7 则回炉修锚点/校准后重评。
6. **可选 judge 上量**：LLM/VLM judge 需先用人工校准集校准；事实核查用独立外部参照（重新检索/用户上传源），不采信被测工具中间产物。
7. **可复现留痕**：题集、附件、每项分、评分者、时间戳、工具版本全部公开。

### 公平性红线
- 不为任一工具改写提示词、不额外投喂提示、不挑对某家有利的题。
- 强时效题的检索窗口对所有工具一致；离线/私有化工具若不支持联网，在该题如实记 0，不隐藏其短板、也不因此在其他题补偿。
- 评测者利益关系须披露；利益相关方评分须与独立评分交叉核对。

## 四、附件规范
